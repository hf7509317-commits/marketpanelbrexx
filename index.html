📖 Panduan Cara Isi

Panduan lengkap mengisi data di Developer Panel

Panduan Produk

  • Nama Produk - Nama paket (contoh: Paket Starter 1)
  • Harga - Format Rp X.XXX (contoh: Rp 5.000)
  • RAM - Kapasitas RAM dalam GB
  • DISK - Kapasitas penyimpanan dalam GB
  • CPU - Alokasi CPU dalam persen (%)
  • Deskripsi - Penjelasan singkat produk
  • Kategori - Starter / Business / Premium
Tips: Gunakan kategori untuk mengelompokkan produk

Panduan User

  • Username - Nama unik untuk login (min 3 karakter)
  • Password - Minimal 4 karakter
  • Nama Lengkap - Nama asli user
  • Email - Format email valid
  • No. HP - Nomor telepon aktif
  • Alamat - Alamat lengkap
Tips: User bisa diaktifkan/nonaktifkan kapan saja

Panduan Pengaturan

  • Nama Toko - Nama bisnis Anda
  • Tagline - Slogan toko
  • Telegram Dev - Username untuk notifikasi
  • DANA - Nomor dan nama akun
  • QRIS - URL gambar QRIS
  • Foto Profil - URL foto toko
Tips: Ganti password developer secara rutin

Panduan Order

  • Step 1 - Pilih paket yang diinginkan
  • Step 2 - Isi username panel
  • Step 3 - Pilih metode pembayaran
  • Step 4 - Upload bukti transfer
  • Step 5 - Kirim ke developer
  • Step 6 - Tunggu konfirmasi
Tips: Pastikan bukti transfer jelas terbaca
